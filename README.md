# 收货地址管理微信小程序

一个完整的微信小程序，用于管理用户的收货地址信息。

## 功能特性

### 基础功能
- ✅ 地址列表展示
- ✅ 添加新地址
- ✅ 编辑已有地址
- ✅ 删除地址（滑动删除）
- ✅ 设置默认地址
- ✅ 地区选择器（省市区）
- ✅ 表单验证
- ✅ 地址标签（家/公司/学校）
- ✅ 地址搜索功能

### 高级功能
- ☁️ **多设备云同步** - 使用微信云开发实现跨设备同步
- 📱 离线模式 - 本地数据持久化存储
- 🔄 自动同步 - 增删改操作自动同步到云端
- 💾 数据备份 - 云端备份，数据安全可靠

### 用户体验
- ✨ 流畅动画效果
- 🎯 直观的交互设计
- 🔍 实时搜索过滤
- 📝 友好的空状态提示

## 快速开始

### 1. 安装微信开发者工具

前往 [微信开发者工具官网](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 下载并安装。

### 2. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择本项目目录
4. 填写 AppID（可以使用测试号）
5. 点击"导入"

### 3. 运行项目

项目导入后会自动编译运行，可以在开发者工具中预览效果。

### 4. 开通云同步（可选）

如需使用多设备云同步功能：

1. 在微信开发者工具中点击"云开发"
2. 创建云环境（免费版即可）
3. 创建数据库集合 `addresses`
4. 配置权限：仅创建者可读写

详细步骤请查看 [云同步使用指南](CLOUD_SYNC_GUIDE.md)

## 使用说明

### 地址列表页面

- 展示所有已保存的收货地址
- 默认地址会显示"默认"标签
- 可以对每个地址进行编辑、删除、设为默认等操作
- 点击"添加新地址"按钮可以添加新的收货地址

### 添加/编辑地址页面

- 填写收货人姓名（必填）
- 填写手机号码（必填，会进行格式验证）
- 选择所在地区（必填，支持省市区三级选择）
- 填写详细地址（必填）
- 可选择是否设为默认地址
- 点击"保存"按钮保存地址信息

## 数据存储

本小程序使用微信小程序的 `localStorage` 进行数据持久化存储，数据存储在用户本地。

### 地址数据结构

```javascript
{
  id: "address_1234567890_abc123",    // 唯一标识
  name: "张三",                        // 收货人姓名
  phone: "13800138000",                // 手机号码
  province: "广东省",                   // 省份
  city: "深圳市",                      // 城市
  district: "南山区",                   // 区/县
  detail: "科技园南区XX大厦",           // 详细地址
  isDefault: true,                     // 是否为默认地址
  createTime: 1234567890000,           // 创建时间
  updateTime: 1234567890000            // 更新时间
}
```

## 工具类 API

### addressStorage

地址数据管理工具类，提供以下方法：

#### `getAddressList()`

获取所有地址列表

- 返回：`Array` - 地址列表数组

#### `getAddress(id)`

获取单个地址信息

- 参数：`id` - 地址ID
- 返回：`Object|null` - 地址对象或null

#### `addAddress(address)`

添加新地址

- 参数：`address` - 地址对象（不含id）
- 返回：`Object` - 添加后的地址对象（包含id）

#### `updateAddress(id, address)`

更新地址信息

- 参数：
  - `id` - 地址ID
  - `address` - 地址对象
- 返回：`boolean` - 是否更新成功

#### `deleteAddress(id)`

删除地址

- 参数：`id` - 地址ID
- 返回：`boolean` - 是否删除成功

#### `setDefaultAddress(id)`

设置默认地址

- 参数：`id` - 地址ID
- 返回：`boolean` - 是否设置成功

#### `getDefaultAddress()`

获取默认地址

- 返回：`Object|null` - 默认地址对象或null

#### `clearAllAddress()`

清空所有地址

- 返回：`boolean` - 是否清空成功

## 云同步功能

### 工作模式

小程序支持两种模式：

#### 1. 纯本地模式（默认）
- 不开通云开发 → 自动使用本地模式
- 数据存储在设备 localStorage
- 卸载后数据丢失
- 不同设备独立

#### 2. 云同步模式
- 开通云开发 → 自动启用云同步
- 数据同步到微信云端
- 多设备自动同步
- 支持离线使用

### 云同步特性

- ✅ **自动同步**：增删改操作自动同步云端
- ✅ **多设备访问**：同一账号不同设备数据一致
- ✅ **离线可用**：无网络时正常使用本地缓存
- ✅ **数据安全**：云端备份，永不丢失
- ✅ **降级处理**：云端失败自动使用本地模式

### 如何开通

详细教程请查看 [云同步使用指南](CLOUD_SYNC_GUIDE.md)

1. 微信开发者工具 → 云开发 → 创建环境
2. 数据库 → 创建集合 `addresses`
3. 配置权限：仅创建者可读写
4. 重启小程序，自动开始同步

**免费额度**：完全够用
- 数据库：2GB 存储
- 云函数：1000万次/月
- 个人小程序远不会达到上限

## 注意事项

1. **手机号码验证**：必须是11位数字，以1开头
2. **默认地址规则**：
   - 每个用户只能有一个默认地址
   - 第一个地址自动设为默认
   - 删除默认地址时自动切换
3. **数据存储**：
   - 未开通云开发：本地存储
   - 开通云开发：云端+本地双重存储
4. **滑动删除**：左滑地址卡片显示删除按钮
5. **搜索功能**：支持搜索姓名、电话、地址
